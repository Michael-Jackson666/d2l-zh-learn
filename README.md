# Jack 的深度学习之旅 (Dive into Deep Learning)

欢迎来到我的学习仓库！

这里是我跟随李沐老师的《动手学深度学习》(d2l.ai) 课程进行学习的个人代码、笔记和实验记录。这个仓库的目标是记录我的学习过程，加深对深度学习核心概念的理解，并探索一些有趣的扩展。

*“理解深度学习的最佳方法是学以致用。”*

---

## 仓库内容

*   **`/chapter3_linear-networks`**: 线性神经网络（线性回归、Softmax回归等）的学习代码和笔记。
*   **`/chapter4_multilayer-perceptron`**: 多层感知机的实现和相关理论的总结。
*   **`/chapter5_deep-learning-computation`**: 深度学习计算的学习笔记。
*   **`/chapter6_convolutional-neural-networks`**: 卷积神经网络的学习笔记。
*   **`/chapter7_convolutional-modern`**: 现代卷积神经网络的学习笔记。
*   *... (后续章节会持续更新)*

## 我的学习重点

*   **理论与实践结合**: 不仅复现书中的代码，更要理解每一行代码背后的数学原理。
*   **动手实验**: 积极完成每章的练习题，并尝试调整超参数、修改模型结构来观察结果变化。
*   **代码封装**: 尝试将课程中的代码封装成更模块化、可复用的函数和类。
